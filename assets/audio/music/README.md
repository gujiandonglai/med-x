# 把你的音乐放在这里

把 5 个 mp3 文件放进本文件夹（`assets/audio/music/`），文件名必须**完全一致**（区分大小写，不要中文名、不要空格）：

| 文件名 | 用在哪里 |
|---|---|
| `menu.mp3` | 主菜单 / 英雄选择界面 |
| `act1-bloodvessel.mp3` | 第一幕 · 血管 |
| `act2-lung.mp3` | 第二幕 · 肺部 |
| `act3-liver.mp3` | 第三幕 · 肝脏 |
| `boss.mp3` | 三幕的 Boss 战通用（三场 Boss 战共用这一首） |

放好之后不需要改任何代码、不需要重启 —— 刷新页面即可生效。

## 说明

- 代码里用的是 `audio.loop = true` 做无缝循环播放，所以你准备的 loop 音乐本身首尾要能接上；不需要在文件里留静音头尾。
- 文件名对应关系写死在 `src/audio/AudioManager.js` 顶部的 `MUSIC_TRACKS`，如果你想换文件名或加更多曲目（比如给每幕单独配一首 Boss 曲），改那里的路径表即可。
- 如果某个文件缺失或加载失败，游戏会自动退回到之前那版合成器生成的环境音效（不会报错卡住），控制台会打印一行提示是哪个文件没找到。
- 音量由「设置」里的音乐音量滑条控制。
